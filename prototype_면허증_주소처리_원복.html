TO-BE: "신분증 주소 동일 / 주소 다름" 라디오 버튼(UI-01)이 복원됩니다.
  • AS-IS: 검색으로 고칠 순 있지만, OCR 정확도가 낮아 불완전한 주소를 그대로 보여줘 혼란을 줬습니다(§2.2).
  • "동일"(기본값): 주소 입력 영역이 사라지고, 이후 어드민3 담당자가 사진을 보고 검수합니다.
  • "다름": 그때만 검색 인풋·버튼(UI-02)이 노출됩니다 — 라디오를 눌러보세요.
  • 최초 계약서(일반/보험) 기준. 교체계약서는 최초 선택값을 그대로 노출하며 필요 시 재수정 가능합니다.

  • 동일: OCR 주소 노출, 인풋은 읽기 전용 — 값은 "주소 검색" 또는 "직접 입력" 체크박스로만 바뀝니다.
    • "확인 불가": 값은 그대로 두고 저장 — 검수 못했다는 표시일 뿐, 이후 정정은 렌트업체 몫입니다. "직접 입력"과 동시 선택 불가(상호배타).
    • "직접 입력": 도로명/지번(필수) + 상세 주소(선택) 필드 노출. "확인 불가"와 동시 선택 불가(상호배타).
    • 인풋 호버 시 전체 주소 툴팁 노출.
  • 다름 / 직접 정보 입력: 읽기 전용, 검색·체크박스 미노출 — 고객 확정값이거나 촬영 자체가 없어 라디오 개념이 없는 건입니다.
