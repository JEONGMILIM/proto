TO-BE: 유류량・운전자점수 기능 제거로 평가・정산 탭 콘텐츠가 무효화되어, 탭 구조를 폐기하고 카드 그리드로 재구성했습니다.
  • 제어(AS-IS 유지) + 트래킹 / 운행이력 / 통합관리 3개 카드로 구성 — IMS.connect FMS 소개 자료의 검증된 4개 기능(트래킹・운행이력・통합관리・AI리포트) 중 AI리포트는 제거 대상인 운전자점수 기능과 동일하여 제외
  • 탭 전환 없이 한 화면에서 모든 혜택을 한눈에 볼 수 있도록 구성 — 콘텐츠 기획/개발 부담 감소
  • 카피는 렌터카 사업자 관점(고객・대여・정비 등 실제 업무 맥락)으로 작성, 헤더 A/B・카드별 A/B로 후보 문구를 프로토타입에서 바로 비교할 수 있게 구성 — 최종 문구는 미확정
  • "시작하기" 버튼 아래 IMS.connect 가입・설치 및 계정 연동 문의 전화번호(1600-8348)를 추가 — 기존 로그인 화면에만 있던 안내를 미연동 사용자에게 미리 노출해 진입장벽 완화
  • A안(카드형): "연동하면 뭐가 좋은가(혜택 나열)"에 집중한 원안
  • B안(안내형): 렌터카 대표가 먼저 궁금해할 "Form과 Connect가 왜 연동되는지 · 지금 안 해도 되는지"는 카드 박스 없이 가벼운 2단 텍스트로 짚고, "연동하면 뭐가 좋은지"는 혜택 카드 4개로 적극적으로 보여준 뒤, "연동하기" 버튼 하나로 신규・기존 사용자를 모두 처리(가입 여부에 따른 화면 분기・별도 헤드카피 없음)
  • 2단 텍스트 바로 아래 뱃지 4개(연동 비용 0원 / 기존 데이터 영향 없음 / 언제든 해제 가능 / 설치 없이 1분 연동)를 추가 — 앞의 3개는 "연동해도 안전한가"(비용・기존 데이터・되돌리기), 마지막 1개는 "번거롭지 않은가"(설치・소요시간)에 대한 답으로, 본문을 다 읽지 않아도 3초 안에 의구심을 해소하도록 구성
미확정 · 논의 중: B안(안내형)은 이번 리뷰 과정에서 새로 제안된 방향으로, 확정된 요청서・PRD에는 아직 반영되어 있지 않습니다. A안/B안 중 최종 채택 여부와 B안의 팩트 카드・차량번호 매핑 안내 문구는 리뷰 후 확정이 필요합니다.

"시작하기"/"연동하기" 클릭 시 뜨는 IMS.connect 로그인 화면을 모달로 전환하는 것도 이번 리뷰에서 새로 제안된 방향입니다. 기존 PRD(§1 제외 범위)는 이 로그인 화면을 "이번 이슈와 무관하며 변경 없음"으로 명시하고 있어, 모달 전환을 정식 반영하려면 범위 확장에 대한 별도 합의가 필요합니다(자료/스크린샷 2026-08-18 154802.png 기준으로 재현했으며, 화면 자체가 IMS.form 네이티브 UI라 모달 전환에 기술적 제약은 없는 것으로 확인).
