• 환급금(09.05 10:05 예시): 탁송 요청 취소 시 시스템이 자동 환급(FT-02).
• 일시·만료일 표기: 일시는 Web `yy.mm.dd hh:mm`(2자리), Mobile `yyyy.mm.dd hh:mm`(4자리). 만료일은 별도 컬럼 없이 "내용"에 괄호 병기(yy.mm.dd, 공통).
• Mobile: 설명+금액·재화 배지("A1", 파란/빨강) → 구분 → 일시 순 카드. 행별 잔여 없음. 혼합 차감(1029번 카드)은 1행에 설명과 재화별 금액·배지 2개를 함께 배치, 구분 줄에는 합산 총액(부호 없음).
• 페이지네이션: 20건 — Web 번호 / Mobile 무한 스크롤.
• 노출 조건: (이용 권한 플래그 On 또는 과거 지급 이력 있음)(①) + 직원유형이 대표·매니저·청구직원(②) 모두 충족해야 노출 — 플래그만 켜지고 이력이 없으면 빈 상태로 노출(PRD LD-11, LD-13).
